# experimental/ — per-experiment code, quarantined

One-off programs tied to a specific run or hypothesis. They are records, not
tooling: each file keeps the configuration it ran with (including retired
settings like `FRICTION_COMP = 10`), because changing them would falsify the
lab book entry they produced. Do not "fix" them to match current constants,
and do not import them from core code.

The durable versions of what these learned live elsewhere: the arm/launch
ritual and loop constants in `robot/hubconfig.py`, the gains in
`robot/gains.py`, the fixed-window measurement in `robot/benchmark.py`.

- `sweeps/` — the hypothesis-per-launch sweep family (runs 4–10) and the
  early instrumented balancer. Their docstrings are the reasoning behind
  runs 1–10; the sweep *pattern* (several configs per stand-up, safest
  first, on-hub summary stats) is described in CLAUDE.md.
- `inference/` — the MicroPython inference-speed investigation (run 14):
  native-emitter probe, and the generated benchmark comparing float /
  Q10 / Q12 / interpolated-tanh variants. `_bench_fast*.py` are generated
  by `scripts/make_fast_policy.py`.
- `ab/` — the crossover (ABBA) comparison harness (runs 18, 20–22).
  `_ab_cycle.py` is generated by `make_ab_cycle.py`; note the checked-in
  file is whatever variant ran last (`--pipeline` for run 22), and the
  generator's default is the 3-way build.

This directory is excluded from the public packaging story; a fresh clone
needs nothing in it to train, verify, export, or deploy.
