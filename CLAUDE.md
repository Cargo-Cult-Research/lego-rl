# lego-rl

Sim-to-real RL for a LEGO 42124 rebuilt as a two-wheeled inverted pendulum.
Python in src/lego_rl (MuJoCo sim + SB3 PPO). robot/ is Pybricks/MicroPython
that runs on the Technic Hub — it must never import from the package.

- venv: .venv (uv). Run everything as `.venv/bin/python scripts/...`.
- Sign conventions live in the src/lego_rl/env.py docstring; keep the robot
  code consistent with them or nothing downstream lines up.
- src/lego_rl/params.py carries provenance (MEASURED/DATASHEET/GUESS). When a
  value gets measured, update the number AND its provenance tag.
- The project's verifier: scripts/linearize.py compares the learned policy's
  Jacobian at equilibrium to the four Pybricks reference gains. Do not tweak
  either side to force agreement — a mismatch is a bug to hunt.
- robot/policy_weights.py is generated by scripts/export_policy.py; never
  hand-edit it.
