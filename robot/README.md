# robot/ — everything that runs ON the hub

MicroPython for Pybricks. Nothing here may import from `src/` (the hub can't);
shared constants come from the two config modules below, which `pybricksdev`
bundles into the upload automatically when a program imports them.

Run anything with: `scripts/run_on_hub.sh robot/<file>.py`

## Configuration — edit here, nowhere else

| file | what |
|---|---|
| `hubconfig.py` | THE build: hub orientation, motor wiring, loop constants (DT, V_NOM, FALL_DEG, RATE_TAU_MS, MAX_DUTY), arm ritual. What a different robot edits. |
| `gains.py` | THE control law: the four balance gains + retired terms. Retune via `scripts/tune_gains.py`, paste only here. |

## Programs

| file | what | when to use |
|---|---|---|
| `hub_check.py` | first-boot bringup: firmware, ports, IMU, motor wiggle | new hub / new build |
| `balance_classical.py` | the classical four-gain balancer | baseline, sanity |
| `balance_policy.py` | run a policy module (imports `policy_fast`) | deploy a policy |
| `benchmark.py` | classical law, fixed 10 s window, fixed statistics | comparing builds |
| `play.py` | balance forever, re-arm after falls | poking the robot |
| `sysid_*.py`, `ring_test.py` | measurement tools feeding `src/lego_rl/params.py` — each docstring says which parameter it measures | when a GUESS needs burning down |

Multi-condition crossover sessions (several controllers per battery) are
generated by `experimental/ab/make_ab_cycle.py`.

## Policy modules (Q12 fixed point, generated — never hand-edit)

Regenerate: `scripts/make_fast_policy.py --weights <policies/*.py> --out <name>`.
Float sources live in `policies/`; only these quantised forms run on the hub.

| file | source | status |
|---|---|---|
| `policy_fast.py` | `runs/ppo_balance_seed0` (trained pre-sim-fixes) | **DEPLOYED** — the policy runs 13–26 measured |
| `policy_fast_8m.py` | `runs/ppo_fixedplant_8m_seed1` (trained on the fixed plant: contact fix + backlash) | **DID NOT TRANSFER** (run 27: hot duty, classical quieter 7/7, despite being the best sim policy ever) — kept as the sim-real-gap probe |
| `policy_linear_fast.py` | the classical law via `linear_to_net.py` | **CONTROL** — not a policy; exists to test the export pipeline itself (runs 22, 24, 26) |

When a candidate wins on hardware, it becomes `policy_fast.py` (one `git mv`
plus regenerating the crossover) and this table moves the crown — the table
is the single place that says which policy is current.
